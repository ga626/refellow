# Refellow · 参伴轻采集器 0.3.0：安装与使用

本地开发源码包，未上Chrome / Edge扩展商店；本轮没有替你安装或改浏览器配置。

## 安装

1. 工作台“采集工具”下载并解压collector.zip，确认manifest.json、popup.html、capture.js、recorder.html、shared文件夹在解压根目录。
2. 在你选择的Chrome打开chrome://extensions，或Edge打开edge://extensions。
3. 手动启用开发者模式，加载含manifest.json的解压目录，核对权限，再固定图标。不要选择整个项目或调研目录。
4. 新版工作台导出“目录与工作台地址”；扩展按需打开侧栏，切到“网站”，导入该JSON。默认地址仍是既有公网，未导入配置会回到旧公网工作台。本轮新版地址是http://127.0.0.1:5192/。

## 先收下，再整理

在参考网页点图标，默认只是轻弹窗：

- “截一张”：只截当前可见网页，核对预览，再存收件箱；不自动整页拼接。
- “录一段”：打开独立录制窗，点击开始后自行选择共享目标；不录音、最长15秒。停止后核对画面和具体网址，再保存；取消不会存假录像。默认WebM，浏览器不支持时尝试MP4，不制作GIF。
- “只记网址 / 手动补充”：没有画面也能先收下；名称与备注选填，不要求分类或项目。

收件箱导出含媒体的JSON → 工作台“我的收藏”导入 → 核对合并摘要并确认。同网址追加附件，不覆盖原有名称、借鉴点与项目。

回收藏夹再命名、分类、圈出截图区域，按需粘贴原提示词、参数、官方入口。项目中再标借鉴 / 避免和视频时间段，导出“给AI的参考包”。

## 数据与权限

权限为activeTab、scripting、sidePanel、storage；没有all_urls、cookies、history权限，没有常驻注入或后台扫描。侧栏仅明确点击才开，不默认占满每个网站。受限页面可能无法采集；跨站需重新点图标授权。

截图或录屏仍可能包含私人信息；共享目标的选择不等于自动读到其真实URL，须手动核对。不要采集密码、支付或敏感表单。

媒体在扩展自己的IndexedDB；主站是另一个origin，通过JSON手动交换，不云同步。单媒体12MB、单次媒体包60MB，收件箱50条 / 4MB文字元数据。清理数据或移除扩展前先导出。

右侧网页预览没有扩展权限：“截一张”明确禁用，手动网址路径可实测。真实Chrome/Edge安装、captureVisibleTab与getDisplayMedia系统选择器尚待独立验收；源码和mock测试不能替代。

## 回滚

先导出收件箱，再在扩展管理页移除本扩展；保留导出文件和原主站数据。源码修改前的ZIP快照在对话资料中。收藏与源码不是原站资产复制许可，也不绕过付费或登录。
