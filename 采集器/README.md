# 参伴页面采集器 · 0.5.4本地候选

1. 在参伴网站右上角登录；采集器自动识别账户，不需要连接码。新账户通过邮箱验证码注册，旧账户可使用原用户名登录后验证绑定邮箱。
2. 黄页18站自动显示悬浮圆钮，其他网页点击Edge工具栏显示。首次截图／录屏仍需通过扩展操作授予当前标签页采集权限。
3. 截图：框选或整个可见画面，确认后保存到个人收藏。录像：框选或整个标签页，点击停止后上传，静音。
4. 退出网站同步撤销采集身份。切换账户时，未上传媒体不转存到新账户；保存失败有提示，录像在内存中保留供重试，关闭浏览器可能丢失。

开发版首次使用本机空间：Edge扩展详情→扩展选项→本机开发网站→前往网站登录，允许一次回环权限，再刷新5192网站。以后网站登录自动同步。正式、预览和本机账户／收藏相互隔离。

真实邮件服务尚待配置，不把测试接收器当作邮件送达。网站、worker和扩展须配套验收，详见仓库 docs/account-integration.md。

只申请activeTab、scripting、storage、tabCapture和offscreen，不读取Cookie或密码，不申请全站访问。account-bridge仅在受信参伴网站运行，凭据只在扩展内部传递。采集只包含当前标签页眼睛所见的画面，不含浏览器地址栏、其他桌面软件或声音。

候选绑定源码SHA和PR，须核对release-identity.json；本地候选不是商城发行版。旧popup／sidepanel及收件箱代码保留兼容，不是默认保存流程。
