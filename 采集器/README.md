# Refellow · 参伴悬浮采集器 0.4.0（本地开发源码）

当前不是商店发行候选。正式安装和上架前须冻结可核对源码身份的候选，并完成真实 Edge 验收。

1. 在普通 HTTP / HTTPS 网页点击工具栏参伴图标，临时授权当前页并显示悬浮圆钮。
2. 拖动圆钮到顺手的位置，松开后吸附左／右边缘并记住纵向位置；点击展开菜单，再点收起。方向键移动、Escape 收起。
3. “截一张”保存当前可见画面，截图期间隐藏采集器。“录一段”由你选择共享目标；请选择当前参考网页并核对来源。再点同一按钮停止，也可取消。单段最多120秒 / 12MB，不录音；预览并确认画面和来源后才能保存。
4. 不用时点“隐藏”，再点击浏览器工具栏图标恢复。刷新／导航后重新点击工具栏。内部设置页、扩展商城等受保护页面不能注入。
5. “收件箱”打开普通扩展标签页。导出含媒体 JSON，到配套工作台“我的收藏”导入，同网址追加附件，不覆盖旧名称和备注。
6. 工作台导出目录配置，在收件箱“网站”页导入，可以记住工作台地址和个人来源。默认工作台仍是既有公网；新版配套工作台的公开部署待完成。

权限仅 activeTab、scripting、storage，没有侧栏权限、全站 host 权限或常驻 content_scripts。不读取 Cookie 或表单，不上传云端。截图和录像可能含隐私，保存前请核对。网页预览只有本地交互和手动共享能力，没有扩展截图权限。

媒体在扩展 IndexedDB，元数据在 chrome.storage.local；网页和扩展不同 origin，不自动同步。卸载／清数据前先导出。单媒体12MB，收件箱50条 / 4MB文字元数据，单次媒体包60MB。原站素材许可需自行确认。

public/collector 是共享模块源，sync-collector.mjs 派生 shared，build-floating.mjs 派生 floating.js，不直接修改派生文件。
