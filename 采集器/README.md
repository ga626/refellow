# 参伴页面采集器 · 0.5候选

仅上 Edge。正式安装必须使用绑定 PR／源码提交、摘要核验通过的候选 ZIP。开发目录和普通本地构建不是商城发行包。

1. 网站创建用户名＋密码账户，保存一次性恢复码。
2. 网站账户菜单生成连接码；扩展悬浮菜单的“连接账户”页输入。
3. 普通 HTTPS 网页点击浏览器工具栏参伴图标，出现可拖动、可隐藏的悬浮圆钮。
4. 截图：选择框选或整个可见画面，确认后直接存到网站个人收藏。
5. 录像：框选或整个当前网页可见画面，控件隐藏；点击浏览器工具栏参伴图标停止并保存。无120秒时长限制，静音。接近媒体内存容量时自动停止并保存。
6. 保存失败会提示，点击截图或工具栏重试；网站收藏会自动更新。录像待重试时只在内存，关闭浏览器可能丢失。

采集的是当前标签页眼睛所见的画面，不自动滚动、不录制桌面或声音。内部页面、受保护页面可能不允许采集。网址、标题和媒体发往当前连接的参伴账户；只访问参伴 Pages 域名及其候选预览域名，不常驻扫描全部网页。

activeTab、scripting 用于用户授权的当前网页；tabCapture、offscreen 用于同标签页静音录像和后台上传；storage 保存连接和悬浮位置。截图采用临时 IndexedDB 缓冲抵抗后台休眠，保存／取消后删除，过期缓冲在后台再次运行时清理。旧 popup、sidepanel、导入与本地收件箱代码保留兼容，不是新默认保存流程。

候选预览可在连接页折叠的测试设置中填入同一参伴项目的 HTTPS 预览地址；正式用户保持默认网址。公开前的真实 Edge 验收须使用同一候选，并核对 release-identity.json。
