# Refellow · 参伴采集侧栏 0.2.0

这是本地可用初版，不是已经安装或商店发布的扩展。无需注册、登录、服务器或付费账号。

## 加载

1. 在网站“采集侧栏”页下载源码 ZIP，解压到你愿意长期保留的位置。
2. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点“加载已解压的扩展程序”，选择直接包含 manifest.json 的目录，不是 ZIP 或它外面的父目录。
4. 在扩展拼图菜单中固定“Refellow · 参伴 · 页面采集器”。权限为 activeTab、scripting、sidePanel、storage；没有永久全站读取权限。
5. 在普通 HTTP/HTTPS 网页点击扩展图标，侧栏应打开。Chrome 需116及以上；其他 Chromium 浏览器支持情况需实际验证。

## 日常流程

- 网站工作台里建项目，在“采集侧栏”导出“目录与项目”。侧栏切到“网站”，在“带入自己的目录与项目”导入。
- 侧栏“网站”可搜索入口并在当前标签页打开。新网站会撤销旧 activeTab 权限，需要再次点扩展图标授权。
- 选中文字，再点击“读取当前页与选中文字”。只读取主框架位置、标题和所选文本，不读密码、Cookie、表单值。
- 截图单独点击，只有当前可见区域，不是整页或动画录像。检查敏感信息后保存。
- 设计分类可多选，自由标签记录风格；项目与项目分组单独选择。关键词建议只是辅助，不是页面理解 AI。
- 保存进本地收件箱。相同地址（忽略 UTM 等追踪参数）提示重复，不覆盖原内容；不同 hash 或组件参数保留区别。
- 收件箱导出全部采集包，回到新版网站“我的收藏”导入，查看项目、分组、重复数量后确认。
- 不匹配的项目先留在收藏，不自行创建陌生项目。导入不覆盖已有记录与既有项目借鉴点。

## 限制与故障

- 切换页面后草稿保留，旧截图不可再次抓取，需重新读取。读取前确认替换名称和地址，备注仍保留。
- 内置页、扩展商店、部分受限框架不能注入，退回手动网址与描述。不绕过网站安全策略。
- 收件箱最多50条或4MB，达到上限先导出再移除。存储失败不更新已保存状态。
- 移除可撤销一次；导出不自动删数据。卸载扩展会清理扩展存储，请先导出。
- 网站 localStorage 与扩展 storage.local 是两份存储，通过文件交换，没有自动同步、账号或云端恢复。
- 网页侧栏预览只演示同源码界面，手动保存可用，不能读取其他标签页，不等于扩展真实运行通过。
- 导入目录与项目配置后，顶部“Refellow · 参伴”返回导出配置的工作台地址，使用当前标签页。尚未导入配置时回退到旧公网版；新批量包请回本轮本地新版导入。
- 嵌入预览页可能被内置浏览器拦截下载：使用“单独打开”后导出，同一来源的收件箱仍在。此限制不适用于原生扩展。

## 更新与撤回

更新前导出收件箱。在扩展管理页“重新加载”同一目录的新版源码；不删旧备份。卸载前导出。本轮没有自动安装、启用、改浏览器设置或覆盖公网。
