## 公开商品文字

名称：Refellow · 参伴 · 悬浮采集器

短简介：拖动贴边，随看随收。保存网页截图或静音短录像，保留原网址，稍后整理参考。

详情：在参考网页点击浏览器工具栏的参伴图标，就能唤出轻巧的悬浮圆钮。拖动到顺手的位置，点击展开截图与录制菜单，再点收起；不用时可以隐藏，点击工具栏再次恢复。

“截一张”保存当前可见画面；“录一段”由你选择共享目标，点击开始、再点停止，单段最多120秒或12MB，不录音。录像先预览，再确认画面和来源后保存。收件箱在普通标签页打开，支持同网址追加附件。导出含媒体文件后，可导入配套参考工作台，再命名、分类、圈选和组织项目参考。

采集器仅在用户点击工具栏后访问当前网页，不常驻扫描所有网站。数据保存在本机，不提供自动云同步。截图与共享画面可能包含个人信息，请在保存和分享前检查。网页和扩展的本地数据相互独立，卸载或清数据前请先导出。

检索词草稿：网页截图、参考收集、静音录制、悬浮工具、项目参考。

## Privacy 字段事实

单一用途：由用户主动保存网页参考画面、具体网址与静音短录像，供个人参考工作台整理使用。

| 权限 | 理由 |
| --- | --- |
| activeTab | 点击工具栏后临时取得当前网页的访问权，用于截图和记录当前网址、标题 |
| scripting | 在获授权的顶层网页注入悬浮圆钮及操作菜单；无常驻全站注入 |
| storage | 保存收件箱元数据、工作台目录配置和悬浮位置；媒体另存扩展 IndexedDB |

无 sidePanel、host_permissions、content_scripts 或远程执行代码。正常跳转原网页／工作台不等于云同步。披露实际访问的网址、标题、截图、共享视频以及用户填入的参考说明和配置；不能笼统勾选“不访问任何数据”。具体控制台分类须结合最终字段逐项核对。

图标：现有[128px PNG](../../采集器/icons/icon-128.png)为原创四格徽记；工具栏16/32/48px均已生成。当前网页预览截图不能作为真实扩展截图上传；截图待正式候选在 Edge 中验收后制作。

## 审核说明草稿

无需产品账号。请在普通 HTTPS 页面点击工具栏图标，拖动圆钮并展开菜单。截图后打开“收件箱”，核对画面、标题和原网址。录制时请选择同一参考网页的共享标签，停止后预览并确认来源，再保存。试验丢弃、取消共享与隐藏／恢复。受保护的内部页面不能显示采集器，工具栏会提示。

数据不自动同步到配套网站。收件箱导出 JSON，打开最终已验收的配套工作台地址，通过“我的收藏”导入，核对媒体与网址。正式申报须填入配套工作台已交付版本和地址，不能让审核员访问开发者的 localhost。
