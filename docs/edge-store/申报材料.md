## 商品描述

Refellow · 参伴页面采集器，把看中的网页画面和具体网址收进个人参考工作台。工具栏点击后出现可拖动贴边圆钮，展开截图／录制菜单，不用时收起或隐藏。

截图支持框选和整个当前网页可见画面。录像支持区域或整个当前标签页的可见画面，静音、手动停止；录制时控件隐藏，点击浏览器工具栏图标停止并保存。无需系统共享目标选择，不捕获桌面或其他标签页。

网站用用户名＋密码登录；生成一次性连接码后连接扩展。截图确认、录像停止后直接上传到对应账户的私人收藏。其他用户不能读取。回网站整理名称、分类、圈选与项目借鉴点，再主动导出含实际媒体的AI参考包。没有自动调用模型或广告跟踪。

## 权限理由

| 权限 | 用途 |
| --- | --- |
| activeTab | 用户点击工具栏后获得当前页临时权限，读取网址、标题和截图 |
| scripting | 只在用户授权的当前顶层网页注入悬浮按钮和框选工具，无常驻扫描 |
| storage | 扩展连接token、用户名、网站地址和悬浮位置；旧版数据留作兼容 |
| tabCapture | 采集用户主动选择的当前网页画面流，不录音、不读取其他标签页 |
| offscreen | MV3后台录制、裁切、编码和上传，并抵抗后台service worker休眠 |
| 可选 http://127.0.0.1/* | 仅用户选择本机测试空间并主动连接时申请；代码限定固定5192端口，本机开发API保存测试媒体，不访问其他内网主机 |
| host_permissions | 仅https://lingganji.pages.dev/*及https://*.lingganji.pages.dev/*，访问自家生产／候选API保存采集内容；不是全网站访问 |

无sidePanel或远程执行代码。黄页18站通过限定匹配的content_scripts自动显示悬浮入口；真实采集仍需当前页临时授权。必须披露访问的网址／标题、画面与静音录像、账户连接信息及上传用途，不能勾选“不访问数据”。公开隐私政策路径：配套网站 /privacy.html；须先核验实际生产部署，再填写最终HTTPS地址。

## 审核说明

需要网站账户。正式申报应提供专用审核测试账号，或说明审核员可自行注册免费账户并保存一次性恢复码；测试账号密码只放Partner Center审核私有字段，不进Git、公开描述或报告。

1. 打开配套生产网站创建账户，账户菜单点“连接采集器”，将一次性码粘贴到扩展连接页。
2. 打开普通HTTPS页面（如example.org），点工具栏参伴图标，测试拖动、展开／收起、隐藏／恢复。
3. 点截图，框选一个区域并确认；网站“我的收藏”应显示对应裁切画面和原网址。另测整个可见画面与取消。
4. 点录像，选择区域或整个当前网页；点击工具栏图标停止。网站出现可播放的静音录像。录制控件不进入视频，无120秒时间截断。
5. 换到另一个网站账户，不能查看前一账户的媒体；账户菜单可断开所有采集器或删除本账户。
6. 受保护的浏览器内部页面不能采集，应返回明确工具栏提示。
