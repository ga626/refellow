# Refellow · 参伴采集器隐私政策（草稿，尚未公开生效）

草稿日期：2026-10-11。责任主体、支持联系方式、正式生效日期与公开网址待真实开发者提供；本文件不能直接用作商店已上线的政策 URL。

参伴采集器帮助用户主动保存网页参考，不提供自动云同步、产品账号后台或自动模型调用。

## 访问和保存的数据

用户点击扩展图标后，采集器访问当前网页的网址和标题，并在页面显示悬浮操作菜单。用户选择截图时，保存当前可见画面；选择录制时，浏览器要求用户选择共享目标，采集器保存静音视频，不录制音频。用户主动整理或导入的参考可能包含选中文字、说明、标签、分类、项目资料和工作台地址配置。

画面、网址及用户资料可能包含个人信息。录制前请选择正确目标，保存前核对画面和来源；不需要的录像可以取消或丢弃。采集器不主动读取 Cookie、密码或表单字段；截图仍可能显示页面上可见的这些内容。

## 本地存储和数据流向

扩展元数据与设置存于浏览器扩展本地存储，图片和视频存于扩展 IndexedDB。配套网站使用独立的浏览器存储，扩展与网站之间不自动同步。开发者服务器不接收采集内容，扩展没有遥测或广告跟踪接口。

用户导出 JSON／ZIP 时，文件包含实际媒体及参考内容；用户自行决定导入工作台、分享文件或交给 AI。打开来源网站、工作台或浏览器扩展商店会受相应服务的隐私政策约束。向其他服务上传导出文件是用户另行选择的操作。

## 删除与保留

本地记录保留至用户删除记录、清除扩展数据或卸载扩展。网站数据、扩展数据及已下载的导出文件是不同副本，删除其中一份不会自动删除其余副本。清除数据或卸载前可先导出完整备份；用户自行删除已下载或已分享的文件。
