# Refellow 0.5.5

首个整合网站、个人云空间和 Edge 页面采集器的公开版本。源码与制品在同一仓库维护，原创代码 MIT，免费使用。

## 变化

- 从侧栏改为可拖动悬浮入口；黄页18站自动显示，其他站点点击工具栏启用。
- 截图支持可视框选、移动、八方向调整、Enter确认、Esc取消及整个可见画面。
- 支持当前标签页区域／整个可见画面的静音录制，手动停止并上传；不设120秒截断，保留容量保护。
- 网站登录后自动关联采集器，截图、录像按账户保存并可在网站查看。
- 邮箱注册、绑定和密码找回接入真实邮件；保留账号注册及一次展示的恢复密钥。
- 右上角账户入口、头像昵称、收藏和项目参考整理、实际媒体导出。
- 固定开发与正式两站，数据库隔离；开发分支可独立更新预览，正式站只能提升已合并 PR 的同一候选。

## 范围

采集仅限当前网页可见画面，不支持桌面、音频、自动长截图或浏览器内部页面。单份媒体上限64 MiB、账户媒体128 MiB；录制达到缓冲容量会停止并尝试保存。旧本地收藏保留，用户可主动导入。

## 验收与渠道

制品必须绑定 PR #2、冻结源码SHA与SHA-256，完成同一制品的真实 Edge 和云端必要验收后发布。具体 CI、下载摘要、生产部署和 Edge 商城审核结果见 [发布状态](../release-status.md)；“已提交审核”不等于已上架可搜索。
